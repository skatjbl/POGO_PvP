# 포고 PvP 상성 도우미 (안드로이드)

포켓몬고 배틀 화면을 읽어(화면 캡처 + 한국어 OCR) 상대/내 포켓몬을 찾고, 타입 상성을 떠 있는 창에 표시합니다.
데이터: PokeAPI(한국어 이름), PvPoke(타입, 랭킹, 추천 기술세트 — POGOMATE가 사용하는 것과 같은 원본).

## APK 만들기 (둘 중 하나)
A. Android Studio: 폴더를 열고 Build > Build APK(s). 만들어진 app-debug.apk를 폰에 설치.
B. 설치 없이: GitHub에 새 저장소를 만들고 이 폴더 내용을 올리면 Actions가 자동 빌드합니다.
   Actions > Build APK > 실행 결과의 pogo-pvp-apk 를 내려받아 폰에 설치(출처 불명 앱 허용 필요).

## 사용
1. 앱 실행 > 오버레이 권한 허용 > 시작(화면 캡처 허용)
2. 갤럭시 폴드 분할 화면으로 포켓몬고 실행. 배틀 화면에서 상대/내 이름이 읽히면 창이 갱신됩니다.
3. 창은 끌어서 이동, 탭하면 슈퍼→하이퍼→마스터 리그 전환(추천 기술 타입이 리그별로 바뀜).

## 알려진 한계 (아직 실기기 테스트 전)
- 위쪽 이름=상대, 아래쪽 이름=나 라고 가정합니다. 실제 배틀 UI와 다르면 OverlayService.handleText 수정 필요.
- 내 포켓몬에 별명을 붙였다면 이름을 못 찾습니다.
- 지역폼(알로라 등)은 이름에 폼 글자가 있을 때만 구분하고, 없으면 기본폼으로 봅니다.
- 접거나 펼쳐 화면 크기가 바뀌면 중지 후 다시 시작하세요.
- 기술 타입은 PvPoke의 해당 리그 추천 기술세트 기준이며, 실제 상대가 쓰는 기술과 다를 수 있습니다.
